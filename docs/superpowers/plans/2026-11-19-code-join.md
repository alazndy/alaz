# Join by Code Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A player opens their world to the internet from the menu, gets a code like `K7Q4-XM2P`, and a friend joins with it through a relay at `relay.alazlab.com`, with no port forwarding.

**Architecture:** A new `alaz-relay` binary pairs a host's control connection with a joiner by code, then splices two sockets and stops reading them. `alaz-net` gains a TLS-capable `Stream` under `Conn`, so `Host` receives relay tunnels like `accept()`ed sockets and `Client` can dial the relay. The lockstep protocol is unchanged. A tiny `alaz-relay-proto` crate (no `alaz-sim` dependency) holds the relay messages and the code type, so the relay binary builds fast on the VM.

**Tech Stack:** Rust 2024, std threads (no `tokio`), `rustls` with the `ring` provider, `webpki-roots`, `getrandom`, `postcard`/`serde` (already used), `rcgen` (dev only, test certificates).

**Spec:** `docs/superpowers/specs/2026-11-19-code-join-design.md`

## Global Constraints
- Game and `alaz-net` stay synchronous. No `tokio`/async runtime anywhere. (spec: Kısıtlar)
- Relay host name `relay.alazlab.com`; port **443** (my call, passes firewalls; the VM unit grants `CAP_NET_BIND_SERVICE`). `ALAZ_RELAY=host:port` overrides it for tests and self-hosting only; no other user-supplied relay URL.
- Code: 8 symbols, `XXXX-XXXX`, 32-symbol alphabet without `0 O 1 I`, from `getrandom`; valid while the host's control connection is open; host can get a new code or close.
- Max **8 players** per room (host included). Pairing wait **10 s**.
- TLS on every relay connection: rustls, `ring`, `webpki-roots` (no system roots, no cmake).
- Tunnel rate is throttled (token bucket, large burst), never capped by total bytes; cut only on extreme abuse, counted in a counter. No logging of codes or content, counters only.
- `RELAY_PROTOCOL: u32 = 1`, separate from `alaz_net::PROTOCOL` (stays 2 unless Task 5 changes the snapshot format).
- Never edit files another session is changing: `crates/sim/**` and `crates/game/src/main.rs` only where a task says so; `git status` before each commit, add only your own files.
- `cargo audit` (or the project's tool) after adding dependencies.
- User-facing text is Turkish; commit messages and code docs English.

## Review Focus
1. A joiner types the code in lowercase, with spaces, or as `k7q4xm2p` without the dash, or pastes it with surrounding whitespace or a trailing newline. Expected: accepted. (Task 1 test.)
2. The host quits or the VM restarts while friends are in tunnels. Expected: joiners see "bağlantı koptu", no freeze; relay frees the room. (Task 2 and 4 tests.)
3. Ninth player or a join after "Ağı kapat". Expected: refused with a clear message ("oda dolu", "kod geçersiz"), host unaffected. (Task 2, 4.)
4. Relay unreachable or slow (DNS fails, TLS stalls). Expected: menu shows a red message within the timeout, no frozen frame. (Task 4, 6.)
5. Wrong-code probing. Expected: same reply and same timing for a missing code and an expired one; per-IP lockout after repeated failures. (Task 2.)

### Task 1: `alaz-relay-proto` crate (model: Opus)
**Files:** Create `crates/relay-proto/{Cargo.toml,src/lib.rs}`; add to workspace `members` in `Cargo.toml`.

**Interfaces — Produces:**
```rust
pub const RELAY_PROTOCOL: u32 = 1;
pub const MAX_RELAY_FRAME: usize = 4096;
pub struct Code([u8; 8]);                       // Copy, Eq, Hash, Debug
impl Code { pub fn generate() -> Code; pub fn parse(s: &str) -> Option<Code>; }
impl std::fmt::Display for Code {}              // "XXXX-XXXX"
pub enum ToRelay { Open{protocol:u32}, NewCode, Join{protocol:u32, code:Code}, Accept{id:u64} }
pub enum FromRelay { Opened{code:Code}, Incoming{id:u64}, Paired, Refused(Refusal) }
pub enum Refusal { BadProtocol, NoSuchCode, RoomFull, TooManyAttempts, Busy }
pub fn write_msg<T: Serialize, W: Write>(w: &mut W, m: &T) -> io::Result<()>;   // u32 LE length prefix
pub fn read_msg<T: DeserializeOwned, R: Read>(r: &mut R) -> io::Result<T>;      // rejects len > MAX_RELAY_FRAME
```

### Task 4: `alaz-net` relay support (model: Opus)
**Files:** Create `crates/net/src/{stream.rs,relay_client.rs}`; modify `crates/net/src/lib.rs`, `crates/net/Cargo.toml` (add `alaz-relay-proto`, `rustls` ring, `webpki-roots`; dev-dependency `alaz-relay`, `rcgen`).

**Interfaces — Produces:**
```rust
// stream.rs
pub(crate) enum Stream { Plain(TcpStream), Tls(Box<rustls::StreamOwned<rustls::ClientConnection, TcpStream>>) }   // Read + Write; nonblocking-safe (WouldBlock passes through)
// lib.rs  (Conn::new now takes Stream; existing Host::bind / Client::connect unchanged)
pub const DEFAULT_RELAY: &str = "relay.alazlab.com:443";
pub enum RelayStatus { Connecting, Open(Code), Failed(String), Closed }
impl Host { pub fn open_relay(&mut self, relay: &str) -> Result<(), NetError>; pub fn relay_status(&self) -> RelayStatus; pub fn relay_new_code(&mut self); pub fn relay_close(&mut self); }
impl Client { pub fn connect_code(code: &str, timeout: Duration) -> Result<(Client, World), NetError>; }
pub fn relay_address() -> String;   // ALAZ_RELAY or DEFAULT_RELAY
```
`open_relay` spawns the background thread in `relay_client.rs`: connects (TLS, relay address resolved once), sends `Open`, then for each `Incoming{id}` dials a tunnel (TLS, `Accept{id}`, waits `Paired`), and sends the ready `Stream` over an `mpsc` channel that `Host::poll` drains into `self.waiting` exactly like an `accept()`ed socket. `Client::connect_code` parses the code (`Code::parse`), connects, sends `Join`, waits for `Paired`/`Refused`, then reuses the existing `Hello`/`Welcome` handshake (factor it into a private `handshake(stream, timeout)`). Every wait obeys `timeout`.
